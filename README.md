# Decodelabs-Task-4-OkaforFelix

SALES PERFORMANCE DASHBOARD
DATA VISUALIZATION PROJECT 
(DECODELABS WEEK 4)


Objective:
The objective of this project was to create effective visual representations of business data using Microsoft Excel to communicate insights clearly, support decision-making, and demonstrate storytelling through data visualization.
The project focused on transforming raw transactional data into an interactive dashboard containing charts, pivot tables, KPI indicators, and analytical insights.

Tools Used:
Microsoft Excel.
Pivot Tables.
Pivot Charts.
Excel Dashboard Design.
Slicers & Interactive Filters.
Formulas and Data Analysis Functions.

Data Preparation:
Before visualization, the dataset was cleaned and structured for analysis.
Additional helper columns were created including:
Month
Month Number
Year
High Value Order Classification
The dataset was converted into an Excel Table to improve filtering, formulas, and dashboard functionality.

Dashboard Components:
KPI Cards
Total Revenue
Total Orders
Average Order Value
Total Quantity Sold
Total Customers
Return Rate
Cancellation Rate





Pivot Tables Created (7)
Sales by Product
Monthly Revenue Trend
Payment Method Analysis
Order Status Breakdown
Referral Source Performance
Quantity Sold by Product
Daily Revenue Trend
Charts Created (7):
Clustered Bar Chart = Sales by Product
Line Chart = Monthly Revenue Trend
Pie Chart = Payment Method Distribution
Doughnut Chart = Order Status Breakdown
Column Chart = Referral Source Performance
Bar Chart = Quantity Sold by Product
Line Chart with Markers = Daily Revenue Trend
Interactive Features:
The dashboard includes slicers for:
Month
Product
Payment Method
Order Status
Referral Source
These filters allow users to interactively explore 
trends and insights.

Key Insights & Findings:
1. Product Performance Analysis:
Product analysis revealed that some products generated significantly higher revenue compared to others.
Top-performing products contributed the largest share of sales revenue and quantity sold, indicating stronger customer demand and better market performance.
This insight helps businesses identify products that drive profitability.

2. Revenue Trend Analysis:
Monthly and daily trend charts showed changes in revenue performance over time.
Some months displayed stronger sales activity, suggesting seasonal or promotional effects on customer purchasing behavior.
Revenue trend monitoring can support forecasting and strategic planning.

3. Customer Payment Behavior:
Payment method analysis highlighted customer preferences in transaction behavior.
Certain payment channels were used more frequently than others, showing which payment systems customers prefer for purchases.
Understanding payment behavior can help 
improve customer convenience and operational efficiency.



4. Order Fulfillment Performance:
Order status analysis demonstrated the distribution of delivered, processing, cancelled, and returned orders.
Delivered orders represented the largest portion of transactions, indicating overall operational effectiveness.
Return and cancellation rates provide useful indicators for monitoring customer satisfaction and fulfillment quality.

5. Marketing & Referral Source Analysis:
Referral source analysis identified the strongest traffic and revenue generating channels.
Some channels contributed more revenue than others, showing which marketing sources have greater business impact.
These insights can guide future marketing investment and customer acquisition strategies.

6. Quantity Sold Analysis:
Quantity analysis helped identify products with high purchasing frequency.
Products with strong quantity performance may represent high customer demand, inventory priorities, or popular offerings.

Conclusion:
This project successfully demonstrated the use of Microsoft Excel for professional data visualization and storytelling with data.
Using pivot tables, charts, KPI cards, slicers, and dashboard design techniques, the raw dataset was transformed into an interactive analytical dashboard.
The dashboard communicates business insights clearly, supports data driven decision making, and fulfills the objectives of the DecodeLabs Week 4 Data Visualization project.
